# Creating First Project

- Open [App.jsx] and write your project code and see the changes in `http://localhost:5173` by using the command `npm run dev` in [Node.js] terminal
- Open Page link using [Cmd+click]
- Make changes and see changes in chrome directly (OR) refresh page to see changes


# Pushing First Project into Github

- Open terminal inside project folder   [Ctrl+`]
-  `git init`
-  `git add .`
-  `git commit -m "commit message"`
-  `git branch -M main`
-  `git remote add origin https://github.com/username/repositoryname.git`
-  `git push -u origin main`
- For new changes `git add .`   OR `git add path/to/file`
- `git commit -m "new commit message"` 
- `git push`
