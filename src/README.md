# Creating First React Project

- Created a folder on Desktop
- Opened the same folder in VSCodium in macOS
- Open terminal in same project   [Ctrl+`]
-  `npm create vite@latest .`
-  `y`
-  `React`
-  `Javascript`
-  `ESlint`
-  `yes`
- You will see `http://localhost:5173/` which means react project is running.

- Open [App.jsx] and write your code and see the changes in `http://localhost:5173` by `npm run dev` in terminal
- Open link using [Cmd+click]
